# Image Caption Generator

This project is an image captioning system that generates a text description for a given image. It uses a Vision Transformer (ViT) to understand the visual content of an image and GPT-2 to generate a corresponding caption. The two models are connected through cross-attention, allowing the language model to use the visual features extracted by the image encoder while generating the caption.

The project is implemented using PyTorch and Hugging Face Transformers and is trained on the Flickr8k dataset. A Gradio application is also included for generating captions through a simple web interface.

## BLEU Scores

The model is evaluated using BLEU scores from BLEU-1 to BLEU-4.

| Metric |       Score |
| ------ | ----------: |
| BLEU-1 |    0.6835   |
| BLEU-2 |    0.4882   |
| BLEU-3 |    0.3489   |
| BLEU-4 |    0.2486   |

## Dataset

The project uses the Flickr8k dataset, a commonly used dataset for image captioning. It contains around 8,000 images, with five human-written captions associated with each image. The multiple captions for each image provide different ways of describing the same visual content, which makes the dataset suitable for training and evaluating image captioning models.

The dataset is not included in this repository. It needs to be downloaded separately.

Dataset: https://www.kaggle.com/datasets/adityajn105/flickr8k

After downloading the dataset, place the image and caption files in the location expected by `src/dataset.py`.

## Model

The model consists of two main components:

* ViT (`google/vit-base-patch16-224-in21k`) is used as the image encoder to extract visual features.
* GPT-2 is used as the text decoder to generate the caption.
* Cross-attention allows GPT-2 to attend to the visual features produced by the ViT encoder.
* A visual projection layer is used when required to match the dimensions of the encoder and decoder.

Most of the pretrained parameters are kept frozen, while the parts required to connect the visual and language components are trained for the captioning task.

## Running the Project

Since the trained checkpoint is not included, the recommended execution order is:

### 1. Install the requirements

Create a Python environment and install the dependencies:

```bash
pip install -r requirements.txt
```

### 2. Download and prepare Flickr8k

Download the Flickr8k dataset from the link provided above and make sure the image and caption files are placed where `src/dataset.py` expects them.

### 3. Train the model

Run the training script:

```bash
python src/train.py
```

The training script trains the ViT-GPT-2 image captioning model and saves the best model checkpoint as `best_model.pt`.

### 4. Evaluate the model

Once training is complete, evaluate the trained model:

```bash
python src/evaluate.py
```

This generates captions for the evaluation data and calculates the BLEU scores.

### 5. Generate captions for an image

After obtaining the trained checkpoint, use:

```bash
python src/predict.py
```

The prediction script loads the trained model and generates a caption for the provided image.

## Gradio Application

The project also includes `app.py`, which provides a Gradio interface for using the trained model.

Run it with:

```bash
python app.py
```

The application allows an image to be uploaded and returns the caption generated by the model.
